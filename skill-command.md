# Skill Command Registry

Daftar perintah cepat dan otomasi sistem yang dapat dijalankan langsung melalui suara, menu, atau otomatisasi AI.
File ini dapat diedit langsung oleh manusia atau dikelola melalui UI Skill Command.

| Nama Skill | Deskripsi | Command / Script |
| :--- | :--- | :--- |
| Buka Browser | Membuka web browser bawaan sistem | `xdg-open https://google.com` |
| Buka Kalkulator | Membuka aplikasi kalkulator sistem | `gnome-calculator` |
